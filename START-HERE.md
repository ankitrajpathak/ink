# Your INK app

All source code is in this folder. No paid services are required to explore the demo.

1. Extract the ZIP.
2. Upload the extracted contents to a new GitHub repository. `package.json` must be at the repository root.
3. Import that repository into Vercel as a Next.js project.
4. Deploy with `pnpm install --frozen-lockfile` and `pnpm build`.
5. Explore the app immediately. Add live provider keys later using `.env.example` as your guide.

Read [README.md](README.md) for step-by-step GitHub Desktop, GitHub website, local setup and deployment instructions. Read [docs/ADAPTERS.md](docs/ADAPTERS.md) to connect live sources and [docs/QA.md](docs/QA.md) for the validation results and limitations.

Do not upload the ZIP as the only repository file. Upload its extracted contents, including hidden configuration files. Never commit `.env.local` or real API keys.
